정리 (Cauchy-Schwarz 부등식)

임의의 실수 a₁, a₂, …, aₙ과 b₁, b₂, …, bₙ에 대하여 (Σ aᵢbᵢ)² ≤ (Σ aᵢ²)(Σ bᵢ²) 가 성립한다.

증명.

①
함수 f(t) = Σ(aᵢ t + bᵢ)² 를 정의한다.
증명을 위한 보조 함수 도입
②
전개하면 f(t) = (Σaᵢ²)t² + 2(Σaᵢbᵢ)t + Σbᵢ² 의 t에 대한 이차식이 된다.
분배법칙으로 전개
③
f(t)는 제곱항의 합이므로 모든 실수 t에 대해 f(t) ≥ 0 이다.
실수의 제곱은 음이 아님
④
이차식이 항상 음이 아니려면 판별식이 0 이하여야 한다. 즉
D = 4(Σaᵢbᵢ)² − 4(Σaᵢ²)(Σbᵢ²) ≤ 0
이차함수의 판별식 조건
⑤
양변을 4로 나누고 정리하면 (Σaᵢbᵢ)² ≤ (Σaᵢ²)(Σbᵢ²) 이다.
결론
Q.E.D.
