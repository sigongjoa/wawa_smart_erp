### 학생 앱에서 바로 쓸 수 있는 것
- **단어 시험 (VocabExam)** — `CSAT 빈출 단어` 카탈로그(635개)가 전 학생에게 노출. 응시하면 단어가 내 단어장에 쌓이고 단어 가챠/도감이 채워집니다.
  - 이렐리아·에코(고1)에게는 **의학 단어** 카탈로그도 추가 배정되어 카탈로그가 2개 보입니다.
- **과제 (Assignments)** — 협곡점 과제 2건이 배정되어 있습니다.
  - `6월 수학 수행평가` (수학반 6명 대상, 사진 업로드형)
  - `단어 시험 준비 안내` (전원 8명 대상)
- **캘린더 (Calendar)** — 학생 본인 수업 일정(시간표 기반) 표시.
- **마이페이지 (Me)** — 프로필 확인 및 PIN 변경.

> 단어 가챠·도감·홈 화면의 수집 현황은 **학생이 단어 시험을 풀수록** 채워지는 구조라,
> 처음 로그인 시에는 비어 있는 게 정상입니다(실제 학생 첫 사용과 동일).

## 3. 빠른 시나리오 (체험 추천 순서)

1. **원장으로 데스크톱 로그인** (`test-canyon` / 협곡원장 / 1234)
   → 학생 목록 → 한 학생 프로필 → 출석/성적/리포트 확인
2. **시험·성적** 메뉴에서 4월 월말평가 성적 입력/리포트 생성 흐름 체험
3. **학생 앱 로그인** (`test-canyon` / 이즈리얼 / 1001)
   → [단어 시험]에서 CSAT 단어 응시 → [과제]에서 배정된 과제 확인
4. 다시 데스크톱에서 **과제 검토 큐**나 **단어 관리**로 학생 활동 확인

## 4. 운영/재현 정보 (관리자용)

- 학생 PIN 활성화 시드: `workers/seeds/local/seed-canyon-student-login.sql`
  - 적용: `npm run db:apply:production -- seeds/local/seed-canyon-student-login.sql`
  - 멱등(재실행 안전): UPDATE + INSERT OR REPLACE
- 변경 전 학생 상태 백업: `workers/claudedocs/backups/20260617_canyon_students_pre_login.json`
- PIN 해시는 `pbkdf2$100000$...` (utils/crypto.ts). PIN 재계산은 Node `crypto.pbkdf2Sync(pin, salt, 100000, 32, 'sha256')`.
- **prod 데이터입니다.** 학생 데이터 추가/수정 시 `academy_id='acad-5386360c'` 격리 필수.

### 비고
- prod에는 개념 가챠(`gacha_cards`) 테이블이 없습니다 — 학생 가챠는 **단어(vocab) 가챠** 경로입니다.
- PIN 분실/초기화는 데스크톱 학생 관리에서 PIN 재설정으로 가능합니다.
