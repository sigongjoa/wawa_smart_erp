왜 3 단계인가.

apps/student/src/pages/Writing{Draft,Meta,Review}Page — 학습이론 기반 강제 흐름
STEP 1 · DRAFT
학생이 자기 손으로 먼저 쓴다
주제·조건 제시 → 학생이 시간 안에 직접 초고 작성.
AI 사용: 없음
목적: 현재 실력 측정 + 대필 차단
학생의 진짜 출발점이 남는다 — 학교가 인정하는 학습 증거.
STEP 2 · META
"왜 이렇게 썼는지" 자기 설명
초고를 다시 읽고, 각 문장의 의도·근거를 학생이 직접 메모.
AI 사용: 가이드 질문만
목적: 메타인지 · 자기 사고 가시화
이 단계가 우리만 한다 — 라이팅 첨삭 시장이 못 가진 학습이론 차별점.
STEP 3 · REVIEW
AI 첨삭 + 강사 교정 + 환류
AI가 1차 첨삭. 강사가 코멘트 추가. 강사 교정 = 학원 데이터셋 환류.
AI 사용: Claude 첨삭
목적: 학생 학습 + 학원 자산 누적
AskAI의 teacher-in-loop와 동일 환류 구조.
— 학습이론 근거
Flavell의 메타인지 전략 · Kolb의 경험학습 사이클이 학생-사고 우선 흐름의 이론적 근거.
— 정책 차별성
학교 AI 검출기 시대 → "AI가 대신 써줌" 도구는 사라진다. 학생 사고 강제 흐름이 정답.

어휘는 암기가 아니라 추론이다.

Root Inference · MedTerm — 단어 외우기 시장이 못 푼 두 갈래

— LEFT · Root Inference (어근 추론 평가)

  • i.
    처음 보는 단어 → 어근으로 의미 추론
    "bio-graphy" · "auto-mat-ic" 분해 후 추론. 단어 못 외워도 의미 도달.
  • ii.
    평가 기반 학습
    RootInferenceExamPage — 학생이 어근 분해 → 의미 선택. 맞히면 카드 획득.
  • iii.
    RootStudyPage — 어근 학습
    자주 쓰는 어근·접두사·접미사 학습 모듈. 의학·법·공학 분야 전이 가능.
  • iv.
    왜 차별점인가
    기존 단어장(스픽업·해커스)은 1:1 매칭 암기. 우리는 메커니즘 학습.

— RIGHT · MedTerm Niche (의학영어)

  • i.
    의학용어 = 어근의 결정체
    "cardio-vascul-ar" · "neuro-pathy" — 어근만 알면 모든 의학용어 추론 가능.
  • ii.
    독점적 시장
    의대생 · 간호사 · 의료종사자 · 의학영어 시험(USMLE) — B2C niche로 분리 매각 가능.
  • iii.
    cetz figure 자체 lib
    workers/src/routes/medterm-figures-handler — 학원 자체 의학 다이어그램. 콘텐츠 moat.
  • iv.
    MedTermExamsPage + AdminPage
    강사 출제 + 학생 응시 + 자동 채점 + 약점 환류 (Drill 연결).
