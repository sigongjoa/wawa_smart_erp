기술은 흔하다. 조합이 차별이다.

레퍼런스 스택을 하나로 묶은 end-to-end 파이프라인이 진짜 자산

— LEFT · 기술 스택 (각자는 흔한 것)

  • i.
    React 웹앱 앱 설치 없이 웹에서 (PWA) + 학생↔강사 직통 화상 WebRTC P2P
    갤럭시탭 A8 (학생) + 데스크톱 Chrome (강사). 중계 서버 비용 0.
  • ii.
    Supabase (Auth · Realtime · RLS)
    PostgreSQL + 시그널링 + 학원 격리 RLS.
  • iii.
    Cloudflare 서버리스 (저장·연산·큐)
    녹화 저장 + 음성→문자 변환 큐 + 리포트 생성 자동.
  • iv.
    Claude Sonnet + NCP SENS
    요약 생성 + 카톡 알림톡 발송 자동화.

— RIGHT · 시장 포지셔닝

  • i.
    1:1 과외 시장 — 매우 큼
    국내 시간제 과외만 수 천억대. 운영툴 없음 = 강사 손 작업.
  • ii.
    SaaS화 가능한 모듈
    학원 내장이 아니라 개별 강사 / 소형 학원에도 그대로 팔 수 있음. 별 repo.
  • iii.
    에듀테크 인수 트리거 1순위
    "수업 후 자동화"는 모든 학원이 원함. 클래스팅·아이스크림 같은 곳이 탐낼 자산.
  • iv.
    학부모 카톡 알림톡
    NPS 가장 강한 채널. 한국 시장 특화 — 글로벌 OEM이 못 따라옴.

1
메인 캔버스 · 빨간펜 첨삭

2
양방향 카메라 (좌·우)
좌상단 학생 카메라 · 우상단 강사 카메라 + 마이크·카메라 토글. 학생↔강사 직통 화상 (중계 서버 0).
3
7-tool 툴바 · 펜 굵기·색상
펜 · 형광 · 지우개 · 도형 + 5색 팔레트 + 3 굵기 + 줌. 강사 워크플로 그대로.
4
상단 상태 표시 (idle / live)
우상단 idle 또는 라이브 시 변경. 학생도 같은 표시 — 상태 동기화 시각화.
5
우하단 "종료" → AI 리포트 트리거
한 번 클릭 → 녹화 종료 → 음성→문자 → AI 요약 → 카톡 알림 7단계 자동 발화.
