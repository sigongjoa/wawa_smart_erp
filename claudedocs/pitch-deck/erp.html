01 · ERP · 학원별 분리 + 3-앱
와와 · ERP

다지점 확장은 코드 수정 0.
학원 ID 한 줄만 추가하면 끝.

코드 레벨에서 학원 격리 · 역할별 3 앱이 페르소나 분리

— LEFT · 학원별 자동 분리 (코딩 강제 사항)

  • i.
    모든 DB 조회에 학원 ID 필터 강제
    학생·시험·과제 모든 조회/수정/삭제. 데이터 누출 0.
  • ii.
    파일 저장 경로에도 학원 ID 포함
    사진·증명·자료 저장도 학원별 폴더 분리 — 학원 간 접근 불가.
  • iii.
    로그인 PIN·공유 토큰에 위변조 차단 서명
    학원별 비밀 키. 다른 학원 위변조 불가.
  • iv.
    신규 학원 = DB 한 줄 추가
    코드 변경 없이 학원 추가. 프랜차이즈 즉시 분리.

— RIGHT · 3-앱 구조 (역할별 페르소나)

  • i.
    apps/desktop — 강사용
    학원 운영 전반. 18 모듈 모두. 권위 있는 톤.
  • ii.
    apps/student — 학생용
    모바일 우선. 학습·시험·가챠. 게임 폴리시 톤.
  • iii.
    apps/student (parent mode)
    학부모 read-only 링크. 방문 0으로 자녀 현황.
  • iv.
    디자인 시스템 별도
    design/system/DESKTOP.md · STUDENT.md. 톤 분리로 사용자 혼동 0.

강사가 매일 보는 실제 화면.

apps/desktop · HomeroomPage · 알파시티점 / 서재용 강사 · 라이브 프로덕션 캡처
1
학원 · 강사 컨텍스트
좌상단 알파시티점 ERP 좌하단 서재용 관리자 — 학원·강사 컨텍스트가 항상 보임. 학원별 자동 분리 시각화.
2
담임 요약 4 카드
담임 학생 · 이번달 상담 · 7일내 후속 · 14일내 시험 — 학기 진행 한눈에.
3
월별 상담 매트릭스
학생 × 날짜 그리드. 월1회 / 시험전 / 시험후 / 수시 — 상담 누락 0으로 강제.
4
사이드바 = 18+ 모듈 트리
수업 · 학생 · 담임 · 학습(수학) · 학습(영단어) · 학원일정 · 학원관리 · 설정 — 학원 운영 전체가 한 화면.
5
교과 메모 종합
하단 학생별 우려·총 메모. 차주 상담·코멘트 우선순위 자동. 강사 학기 작업의 본부.
